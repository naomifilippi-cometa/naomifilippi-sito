# naomifilippi.it

Sito statico (HTML, CSS, JS) di Naomi Filippi, consulenza di carriera.

- `supabase/setup.sql`: tabelle, regole di accesso e archivio file

`GUIDA-SETUP.md`, `supabase/` e questo file non vengono pubblicati (vedi `.vercelignore`).
